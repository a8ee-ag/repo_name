# Работа 9. Прогнозирование стоимости квартиры

Модель предсказывает стоимость квартиры по площади, числу комнат, этажу,
городу и району. Интерфейс — Streamlit.

## Структура

| Файл | Назначение |
|---|---|
| `data.py` | загрузка датасета из `DataSet/train_data.zip` и очистка |
| `train_model.py` | обучение модели, сохранение в `artifacts/` |
| `predict.py` | получение предсказания: используется интерфейсом и из консоли |
| `app.py` | интерфейс Streamlit |
| `artifacts/model.joblib` | обученная модель (0.6 МБ) |
| `artifacts/meta.json` | справочники городов, районов, координат и метрики |

## Запуск

Интерфейс (модель уже обучена и лежит в `artifacts/`):

```
streamlit run app.py
```

Переобучить модель заново:

```
python train_model.py
```

Предсказание из консоли, без интерфейса:

```
python predict.py --square 56 --rooms 2 --floor 7 --city Москва --district "Тверской район"
```

## Модель

Градиентный бустинг (`HistGradientBoostingRegressor`) на 78 848 объявлениях.
Обучается на логарифме цены: цены скошены вправо на два порядка, и без
логарифмирования ошибку определяли бы единичные дорогие объекты.

Категориальные признаки (город, район) модель обрабатывает нативно —
one-hot раздул бы матрицу, поскольку районов больше сотни.

Качество на отложенной выборке (20% данных, `random_state=42`):

| Метрика | Модель | Бейзлайн |
|---|---|---|
| MAE | 3 220 844 ₽ | 9 831 785 ₽ |
| Медианная ошибка | 1 129 813 ₽ | 4 353 210 ₽ |
| MAPE | 10.6% | 35.1% |
| R² | 0.927 | 0.466 |

Бейзлайн — медианная цена квадратного метра, умноженная на площадь.

## Исходные данные

Архив `train_data.zip` (42 МБ, внутри csv на 185 МБ) в репозиторий не
выкладывается — для запуска интерфейса он не нужен, модель уже обучена.
Он понадобится только для повторного обучения: положите его в общую папку
`DataSet/` рядом с папками работ.
